# Американские фильмы 2010–2020

Учебный проект по веб-разработке на тему «Американские фильмы 2010–2020».

**Разработчик:** Фаленчи Михаил, группа Б9124-09.03.04(6)

## Практическое задание 1 — сайт на HTML

Сайт: https://abyssi0i.github.io/films-site/

### Страницы

| Файл | Содержание |
|------|------------|
| `index.html` | Главная: меню, раздел с рисунками (заготовка галереи), блоки текста с картинками, футер |
| `film.html` | Подробное описание фильма «Начало» (2010): актёры, награды, интересные факты |
| `table.html` | Таблица из 57 фильмов и формы настройки графика, фильтрации и сортировки |

### Использованные элементы HTML

Заголовки, абзацы, списки, раскрывающиеся элементы (`details`/`summary`), гиперссылки, рисунки, таблицы, формы. Оформление задано атрибутами.

### Валидация

Страницы проверяются на [validator.w3.org](https://validator.w3.org/); по заданию допускаются только замечания «Use CSS instead».

## Практическое задание 2 — главная страница по шаблону (HTML + CSS)

Страница: https://abyssi0i.github.io/films-site/practice2/

Файлы в папке `practice2/`: `index.html` (разметка) и `style.css` (стили).

- Вёрстка по шаблону варианта: меню с поиском, галерея из шести изображений, четыре блока основного содержания и боковая колонка о режиссёрах десятилетия.
- Используются блочное, строчное и строчно-блочное отображение элементов, а также flex-контейнеры.
- Все размеры заданы в `rem`, а `1rem` вычисляется от ширины окна. Поэтому при уменьшении экрана страница уменьшается пропорционально и сохраняет структуру.
- В футере указаны год разработки, группа и разработчик.
